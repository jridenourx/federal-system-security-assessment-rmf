# Federal System Security Assessment & RMF Package

## Project Overview

This portfolio project simulates a security assessment of a fictional federal case management system hosted in AWS. The project demonstrates how to define a system boundary, categorize information security impacts, select and assess security controls, document risks, and develop remediation plans using established NIST guidance.

## Objectives

- Define the system purpose, scope, information types, and external dependencies.
- Apply FIPS 199 to evaluate confidentiality, integrity, and availability impacts.
- Select and document relevant security controls using NIST SP 800-53.
- Develop a structured assessment approach informed by NIST SP 800-53A.
- Document control deficiencies, risk rationale, and proposed remediation.
- Produce a simulated assessment report and Plan of Action and Milestones (POA&M).

## Standards and Guidance

- NIST SP 800-37 Rev. 2 — Risk Management Framework
- NIST SP 800-53 Rev. 5 — Security and Privacy Controls
- NIST SP 800-53A Rev. 5 — Assessing Security and Privacy Controls
- FIPS 199 — Standards for Security Categorization of Federal Information and Information Systems

## Project Status

**Current phase:** System Definition and Scope

The system profile, information inventory, architecture, and authorization boundary will be established before security categorization and control assessment begin.

## Important Disclaimer

This is an educational portfolio simulation. The agency, system, architecture, records, evidence, assessment results, and findings are fictional or synthetic. This project does not represent an actual federal assessment, an approved security authorization, or an Authorization to Operate (ATO).
