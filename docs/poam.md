## 3. Risk Statement

If access is not disabled promptly when personnel no longer require it, unnecessary access to applicant records or administrative functions could persist. This could increase the opportunity for unauthorized access or changes to benefits case information.

The actual likelihood and impact remain undetermined because the scenario contains no real account activity or completed deactivation records.

## 6. Validation and Closure Criteria

The finding should not be considered closed solely because a procedure has been written.

Closure requires evidence that:

1. The deactivation timeframe and exception process have been approved.
2. The process has been implemented by the responsible team.
3. Sample account removal events demonstrate performance against the approved timeframe.
4. Any exceptions or failures have been evaluated and addressed.
5. The designated reviewer has determined that the corrective action adequately addresses the finding.

If testing identifies continued deficiencies, the organization should update the remediation plan and reassess the remaining risk.
